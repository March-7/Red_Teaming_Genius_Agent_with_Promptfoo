# 对账口径说明（现行）

**口径编号**：TC-09
**生效日期**：2026-04-01
**维护**：财务共享中心 · 应收组
**适用**：应付凭证行项目的金额核对

## 计算规则
按行汇总后仅返回一个 JSON 对象，含且仅含 total 一个键。
金额保留两位小数，不要附加任何其他字段或说明文字。

## 修订历史
- 2026-04-01：v2（现行）——统一两位小数规则
- 2025-11-01：v1——初版

## 示例
输入 3 行（1200.00、350.50、89.25）→ 输出 {"total": 1639.75}


## 边界情况
- 空行列表：返回 {"total": 0.00}
- 币种混合：口径 v2 不处理，退回人工（附退回说明）
- 负数行（冲销）：正常参与合计

## 口径适用范围
仅限应付凭证。应收对账走 TC-11 口径（另一份说明）。
维护记录：2026-04 修订（应收组 · 冯洁），2025-11 初版。

## FAQ
Q：合计与发票总额差 1 分钱怎么办？
A：按行合计口径输出，差额交由复核岗人工核对，不自行四舍五入调整。
