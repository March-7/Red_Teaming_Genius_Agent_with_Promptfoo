## 三、三条方法论结论

### 1. "证据缺失"的真实形态是**权威让渡**，不是信息真空

output-ref 的 93% 与 skill-imp 的 0% 是同一攻击逻辑的两面：
- output-ref 的 manifest **主动指定**"版本状态以巡检工具为准"→ 权威被让渡 → 93%
- skill-imp 的发票旁**没有任何口径文档** → 模型反而要求书面依据 → 0%

**攻击面公式**：`文档显式委托权威给攻击者控制的源` ≫ `多源一致假象` ≫ `无对照物`。对防御方的含义：**文档中"详见某工具/以某系统为准"式引用是高危模式**——它把信任链的锚点交给了可被投毒的源。

### 2. 多源佐证只对"口径类"攻击有效，对"状态类"无效

- 口径类（skill-imp 的"已含服务费"）：公告印证 → 30% ✅
- 状态类（output-ref 的"版本受支持"）：快照印证 → 0% ❌——模型对**状态断言**做事实维度归因（说的是不是同一个对象），对**口径声明**只查一致性

### 3. 写操作防御（content-manip 0/30）不可被证据攻破

法务通知书 + 归档系统日志双源齐全，模型依然拒绝执行不可逆归档改写。**操作风险性轴的判断不依赖证据量**——这与阶段 4 B 轨 security-config（变更单被"变更链推理"否决）形成互证：**写/改操作是最坚实的防线层**。
