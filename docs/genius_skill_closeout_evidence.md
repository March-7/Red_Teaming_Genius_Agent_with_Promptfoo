# Genius Skill 阶段资料与证据边界

本目录整理代码、离线用例定义和阶段报告。历史报告中的运行引用用于回查，不代表仓库包含对应的私有运行数据，也不代表在新检出中重新验证了历史结论。

## 保留与本地留存

- 保留代码、合成用例和资产、来源元数据与方法文档。评测结果、分类报告及各类别汇总只在本地保留，不纳入当前仓库版本。
- 2026-10-15 报告包含运行轨迹及附件，保留在原本地资料中，不纳入本仓库。历史文件中的对应链接仅为原始位置记录。
- SkillAtlas 原始列表、详情与 shortlist 含第三方原文，不纳入本仓库。来源和复用限制见 `skill-suites/benchmark-multi-risk/stage7-atlas/source-metadata.json`；其中历史 snapshot 路径是原始资料的位置，不是仓库内可用文件。
- 私有运行目录及生成的逐轮摘要不纳入本仓库。历史报告、计划和索引可能保留指向这些文件的路径与摘要哈希；找不到文件时，该证据的验证结果是不可核验，不是通过。
- 从当前版本移除文件不会清除已有提交、旧分支或 PR 中的历史内容；改变仓库可见性之前仍需另行审查这些历史。

## 登记和检查

`source-registry.json` 恢复为原始 12 来源版本，其文件 SHA-256 与 `source-inventory-summary.json` 中登记的哈希一致。后续添加的 SkillAtlas 元数据独立保存；没有修改历史清单中的哈希。

能力登记中 `docs/genius_skill_readiness.md` 的现有内容与登记哈希不符，预期版本目前未找到。部分历史能力、screening 和 pilot 测试还依赖不随仓库分发的运行数据。相应校验必须继续拒绝缺失或不匹配的证据，不能用当前文件替换历史哈希。可移植的合成测试只能证明校验行为，不能证明历史运行结果。

这里的历史报告和配置不构成新的执行授权；任何后续在线评测仍需遵守项目协议及相应的用户授权。

## 可移植测试与历史集成检查

`npm run test:skill:portable` 运行不依赖私有运行结果的 Skill 合同测试，包括对缺失、篡改和越界证据的拒绝检查。运行前需要按项目锁文件准备本地 Python 和 Node 依赖；此入口不会验证历史运行结论。

原有 `npm run test:skill` 保留完整历史集成测试入口。它需要本地留存的历史证据，在干净检出中可能因证据缺失而失败；目前 readiness 历史哈希不符也会使相关校验失败。不要把可移植测试通过解释为完整测试或历史证据验证通过。
