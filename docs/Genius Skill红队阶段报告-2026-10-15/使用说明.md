# 阅读与飞书使用说明

Word 包含阶段概况、方法与模型配置，以及九类定义、流程、结果和代表案例简述。每类一个独立 HTML，共18条精选轨迹，两个模型各九条。旧报告未被覆盖。

打开 `轨迹HTML/index.html` 选择类别。每类默认展示目标效果较清晰的案例，样本列表和文件栏收起。点击“切换样本”查看另一模型；可展开 Skill 载荷、完整推理、按原始顺序排列的工具调用与返回、回复原文和效果复核。点击附件或生成文件卡片，在右侧查看内容并下载可取得的原件。

文件栏显示运行后独立下载的字节；上传文件若被修改，会明确标记为运行后版本。无可核对原件时不伪造预览。所有已取得文件均校验 SHA-256，下载不依赖 Genius 登录。

本地 scorer 的原始标签保留，不等同为 Judge 判定或漏洞结论。统计按九类全部已保存正式结果计算，HTML只精选展示。跨轮任务与载荷有变化；配置类的 DeepSeek 案例来自 v2，与 Qwen v8 不同条件。未形成结果含审批、澄清、错误或未完整留存，不能算安全通过。

复制或导入 Word 到飞书后，在各类 HTML 入口处拖入对应 HTML 文件。Word 本身不执行 HTML，复制正文不会自动带入交互页面。九份 HTML 均为独立文件，无外部脚本、模型请求或攻击载荷执行。飞书内嵌兼容性本次未实测；若预览限制下载，请下载 HTML 后用 Chrome 或 Edge 打开。

`证据索引.json` 记录每条精选案例的 run、结果文件、trace、文件 hash 和统计口径，便于内部回查。原始 trace 中已有的脱敏和截断标记原样保留。
